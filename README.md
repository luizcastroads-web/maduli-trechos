✺ Maduli Citações ✺
O Maduli Citações é uma aplicação web desenvolvida usando HTML, CSS, e JavaScript. Gerando citações aleátorias de várias músicas de Maduli para motivar e trazer reflexões aos usuários e fãs.
✹ Objetivo ✹
O objetivo principal do Maduli Citações é oferecer aos usuários uma fonte de inspiração por meio de citações aleatórias. A meta é criar uma interface simples e fácil de usar, na qual os usuários possam gerar citações com um único clique. 
✹ Design ✹
O Maduli Citações apresenta um design minimalista, e uma foto da artista ao fundo para contribuir a expêriencia de fã. A interface foi projetada para ser limpa e intuitiva, permitindo que os usuários gerem novas citações com facilidade.
✹ Recursos ✹
Citações Aleatórias: O Maduli Citações seleciona frases aleatoriamente a partir de uma coleção, oferecendo aos usuários uma variedade de mensagens inspiradoras.
Geração com um Clique: Os usuários podem gerar uma nova citação com apenas um clique, tornando a busca por inspiração rápida e fácil.
Citações Compartilháveis: As citações geradas podem ser facilmente compartilhadas em redes sociais ou copiadas para uso em outros contextos.
Design Responsivo: A interface é responsiva e se adapta a diferentes tamanhos de tela, garantindo uma experiência fluida em diversos dispositivos.
✹ O que aprendi ✹
Manipulação de Arrays em JavaScript: O desenvolvimento do gerador de citações permitiu aprimorar minhas habilidades na manipulação de arrays em JavaScript, possibilitando a seleção aleatória e a recuperação dinâmica de citações.
Manipulação do DOM: Por meio deste projeto, fortaleci minhas habilidades na manipulação do Document Object Model (DOM) com JavaScript, o que me permitiu atualizar a exibição das citações e gerenciar as interações do usuário de forma eficiente.
Estilização com CSS: O design da interface do gerador de citações aprimorou minhas habilidades em CSS, especialmente na criação de um layout minimalista e visualmente agradável.
